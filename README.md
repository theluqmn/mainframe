# Mainframe

Server management shouldn't be tedious. You can now manage your Linux
server via a user-friendly, scalable web OS interface. Mainframe is the
lightweight, flexible tool that removes friction from anyone to manage
their own server components.

- [ ] Monitor resource consumption
- [ ] Manage your own backend services
- [ ] Domain management

## Installation

To install Mainframe on your Linux server, simply run the following command and
follow the instructions given by the installer:

```bash
curl -sSL [https://github.com/theluqmn/mainframe/raw/refs/heads/main/install.sh]
(https://github.com/theluqmn/mainframe/raw/refs/heads/main/install.sh) | bash
```
